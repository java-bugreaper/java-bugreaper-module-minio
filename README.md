Is part of the BugReaper JAVA test helper framework that simplifies file storage interaction with MINIO in automated tests.
It provides easy configuration, convenient APIs for working with files and objects stored in MINIO,
and built-in assertions, allowing you to write readable and maintainable tests with minimal boilerplate.
